# Lumen-Print-Dataset

##Gathering Data
I decided to continue gathering more lumen print data. Intially it was difficult to find websites to scrape for images, as most places I found either had a mix of lumen and non-lumen prints making data scraping a mess, or only had a few dozen images, which wasn't enough to make a dataset out of. Eventually I ended up scraping Flickr or images labeled 'lumenprint' which gave me around 800 images. 

Gathering the images was also rather difficult, as the website had anti-image scraping mechanisms and there were non-luman print images sprinkled in. After I collected the data I went through and cleaned up the images by cropping of borders, making sure they were all in the same format, etc. My favorite part of the final grid was how all the colors worked together, I feel lumen prints have a pretty distinct color range/pallette which allows for wide versatility in the colors while retaining a sense of cohesivness.
